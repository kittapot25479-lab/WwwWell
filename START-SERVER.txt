========================================
  วิธีเปิดเว็บให้เพลง YouTube ดังได้
========================================

ปัญหา: ถ้าเปิดไฟล์ .html โดยดับเบิลคลิก (file://)
YouTube จะบล็อกเสียง

วิธีแก้ (เลือกอย่างใดอย่างหนึ่ง):

--------------------------------------------------
วิธีที่ 1: ใช้ VS Code + Live Server (ง่ายที่สุด)
--------------------------------------------------
1. ติดตั้ง VS Code
2. ติดตั้ง Extension ชื่อ "Live Server"
3. คลิกขวาที่ไฟล์ index.html → "Open with Live Server"
4. เว็บจะเปิดที่ http://127.0.0.1:5500
5. คลิกที่หน้าเว็บ 1 ครั้ง → เพลงดัง

--------------------------------------------------
วิธีที่ 2: ใช้ Python (มีใน Windows หลายเครื่อง)
--------------------------------------------------
1. เปิดโฟลเดอร์ godmyegxo-site
2. กด Shift + คลิกขวา → "Open PowerShell window here"
3. พิมพ์คำสั่ง:

   python -m http.server 8080

4. เปิดเบราว์เซอร์ไปที่:  http://localhost:8080
5. คลิกที่หน้าเว็บ 1 ครั้ง → เพลงดัง

--------------------------------------------------
วิธีที่ 3: อัปขึ้นโฮสต์ฟรี (ใช้จริง)
--------------------------------------------------
- Cloudflare Pages / Netlify / Vercel
- เชื่อมโดเมน .com
- เพลงจะทำงานปกติ

หมายเหตุ:
- ต้องคลิกที่หน้าเว็บอย่างน้อย 1 ครั้ง (กฎของเบราว์เซอร์)
- ลิงก์เพลง: https://www.youtube.com/watch?v=agneRtEe-t8
